# Skrifter

Alle skrifter er lisensiert under SIL Open Font License 1.1 og distribuert via Fontsource (npm):

- **Archivo** (variabel: vekt 100–900, bredde 62–125 %) – Omnibus-Type
- **Fraunces** (variabel: opsz, vekt, SOFT, WONK) – Undercase Type
- **Martian Mono** (variabel: vekt, bredde) – Evil Martians

`og/` inneholder statiske WOFF-filer for delingsbilder (satori støtter ikke variable skrifter).
